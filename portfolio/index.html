  8. 08

    Unsound Festival

    Year: 2019

    unsound.pl (opens in a new window) ↗

    • HTML
    • SCSS
    • JavaScript
    • PHP
    • Directus

    The website of the Unsound music festival, built together with Grupa Robocza. It is deliberately light on CPU and network: plain HTML, SCSS with CSS modules, minified class names and no framework. The design is minimal and typography-based, with an interactive map of that year's festival venues.

    The backend is PHP, which the client required, with Directus as the CMS and our own panels and modifications.
